
# 🎯 Python Guessing Game

This is my first mini project in Python.  
The program generates a random number between **1 and 100**, and the user has to guess it correctly.

---

## 🔍 Features
- Random number between 1–100  
- User-input-based guessing  
- Instant feedback: Too Big / Too Small  
- Supports "Quit" option  
- Beginner-friendly and simple  

---

## 🛠 Technologies Used
- **Python 3**
- **random** module

## 🧠 How It Works
- The program chooses a number using `random.randint()`
- User enters guess  
- Program compares guess with the target  
- Gives hint until the correct answer  
- Game ends after success or quitting
